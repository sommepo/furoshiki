# Furoshiki

One front for the reader apps (Eden Reader, Azahar Reader, PPSSPP Reader, PCSX2 Reader,
Flycast Reader, Station Reader, and any app that writes its file: `src/library.h`): the games each of them can read, side by side; their reading statistics
added up; and the way into each one's own menu. It starts the right app for a game and
comes back when that app ends. `AGENTS.md` has how it works and how it was checked.
