# 極限脱出 9時間9人9の扉 (BSKJ)

Nine Hours, Nine Persons, Nine Doors (Chunsoft, 2009), the Japanese cartridge `BSKJ`. Script:
`reader/profiles/BSKJ.lua` (2026-11-14). Its guide is `nine-hours-nine-persons-nine-doors`, its
title record `titles/nine-hours-nine-persons-nine-doors.json`.

## What is read

| | |
| --- | --- |
| The novel's narration (the lower screen) | Each paragraph as the game puts it in, a window each (`novel1`, `novel2`…, as many as the page holds), with its characters' places. |
| The talk window above, with the name box | Window `talk`, with the speaker (淳平, ？？？…) and its characters' places. |
| The escape rooms: what Junpei says of what is touched, the items' remarks, the tutorials | The same talk window; their name is `HERO` in the game's data and no name box is shown, so no speaker. |
| The choices (the pairs at the first door, the door choices…) | One line of the channel `choice`, its answers a row each (the question before it comes through the talk window). |
| The file screen's documents (資料, the help pages) | Window `file`, a page at a time, its rows as rows. |

Not read (2026-11-14): which answer the cursor is on (`reader.cursor`: the game keeps it only in
a running routine's locals), the places of a choice's or a file page's characters (drawn
another way than typed text), the file screen's list of titles, the item's name under its
picture, the save menu. A row put in from another caller is logged once with its address.

The places (`reader.layout`): each typed character's cell, as the game draws it, on the screen
the window is on, so that a word is looked up where it is. Checked against screenshots of the
novel (one and several paragraphs on a page) and the talk window.

## How

The game keeps a scene's text in memory as a list of lines, one copy of each, sorted (so the
order in memory says nothing of what is shown), in a Shift-JIS of its own: kanji and katakana
are ordinary pairs, hiragana and common punctuation single bytes, the codes of half-width
katakana read as hiragana (`A6` を, `A7`–`AF` ぁ…っ, `B0` ー, `B1`–`DD` あ…ん; `A1` 。 `A2` 「 `A3` 」
`A4` 、 `A5` …). Voiced hiragana are ordinary pairs (だ is `82 BE`). In a line, ⑲ (`87 52`) is a
short pause, ⑳ (`87 53`) and a letter (and digits) a code (`⑳C5`…`⑳C0` a colour, `⑳n`, `⑳S0`,
`⑳X40` a place on the row), ▼ (`81 A5`) at the end waits for a press. A capital Latin letter of
its own is a picture in the font (a button, an icon), and a run of ideographic spaces pads a row
to the window's edge.

Every text window is an object of one class (vtable `0x020B0484`). Its ninth method,
`0x020180CC`, takes the line (`r1`) and puts it in: the script hooks it, and the caller (`lr`)
says which window it is:

| `lr` | |
| --- | --- |
| `0x02054EE8` | the novel's narration (the object at `0x02209480` in the first scene) |
| `0x0204DB34` | the talk window: the call at `0x0204DB30` has the caller's object in `r5`, and the speaker's name copied to `r5+0xAD` (16 bytes, `&淳平`, `&HERO`) |

Every window types its characters one at a time through one routine, `draw(renderer, code, x,
y)` at `0x0200CB5C` (from the typing at `0x02017B68`, the window in the caller's `r5`): `x` and
`y` are within the window's text area, rows 15 apart, and the renderer says where that area is
(`+0x34`, `+0x38`) and on which screen (`+0x2C`, not 0 for the lower one). The script matches the
line's characters to what is drawn by their codes, in order.

The window's tenth method, `0x02015F9C`, puts a whole row in at once: from `0x02051B0C` a
choice's answers (one call each, the choice object's answers at `+8`, their count at `+4`), from
`0x0203ED18` a file page's rows, four a frame (in plain Shift-JIS: hiragana are pairs there),
from `0x0203E590` and `0x0203EB28` the list of documents and the page's number.

The script checks the instructions it hooks before it hooks anything, so another release of
the cartridge refuses it rather than reading wrongly.

## In the harness

Seen over the prologue, the first room's tutorials and half of the room (the photo frame, the
stove, the kettle, both trunks and their dials, the red file on digital roots, the mirror and the
flashback it brings), and after loading savestates: every line on the screens was emitted once,
with its speaker, and nothing else. Some lines are emitted again when the game shows them again
(an item looked at twice).

The first room in the harness: every step of the guide works with `touch` on the lower screen
(256x192) and `press left`/`right` to turn. The card reader is a close-up of its own: touch the
reader on the door's view (about 220, 95) to go to it, then its slot (160, 100) with a bundle of
cards in hand (`press up` changes what is held); a dial digit takes one touch a step. Past the
door, the first choice (the pairs) comes about 340 presses of A after the B deck's sign. The
choice between doors 4 and 5 was not offered on a first play in the harness: the game went on
to door 4.
